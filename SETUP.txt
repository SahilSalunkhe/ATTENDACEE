CSMU AARAMBH 2026 — Website bundle
===================================

FILES
- index.html: responsive registration UI
- style.css: mobile-first styling
- script.js: validation + google.script.run submission
- config.js: provided Apps Script URL (reference/config only)
- Code.gs: backend source to paste into Apps Script
- SETUP.txt: installation steps

IMPORTANT CONNECTION DETAILS
The provided Apps Script URL is:
https://script.google.com/macros/s/AKfycbx9aTkx0RAPKFqUamYu8DnkT7i5XzPY_8NZjk7bvk2BFcESqxLdm2eeiwtrVBIgkw56/exec

This bundle's front end uses google.script.run, which only works when the page is
served by Google Apps Script HTML Service. It will NOT submit to the backend when
you double-click index.html locally. That is intentional: it avoids the CORS
problem from calling Apps Script with fetch().

SETUP
1. Open the Attendance Management 2026 spreadsheet.
2. Extensions > Apps Script.
3. Replace Code.gs with the provided Code.gs.
4. Change SHEET_NAME in Code.gs to the exact sheet tab name shown at the bottom
   of the spreadsheet. Do not guess it; the screenshot doesn't show the bottom tab.
5. In Apps Script click + > HTML, name it exactly Index, and paste the contents
   of index.html into that HTML file.
6. To preserve the design, copy all CSS from style.css and put it inside a
   <style>...</style> tag in the <head> of Index.html. Copy the JavaScript from
   script.js and put it inside a <script>...</script> tag at the end of Index.html.
   Remove the external style.css, config.js and script.js references when serving
   through Apps Script, unless you separately host those assets.
7. Save all files. Deploy > Manage deployments > Edit > New version > Deploy.
   Ensure it is a Web app, execute as Me, and access is allowed to your intended
   audience by your Google account / institution policy.
8. Open the NEW /exec URL from the deployment. Do not open local index.html to
   test the live submission.
9. Test with a dummy student. Confirm the code displayed on the page matches
   column A on the same row as that student's details.
10. Do not publish for real registrations until the test passes.

NOTE
The config.js URL is the URL supplied in this conversation. If you redeploy and
Google gives a different /exec URL, use the latest deployment URL.
